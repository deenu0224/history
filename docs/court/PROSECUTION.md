# 공소장 — 「결록」 게임성 출시 수준 미달 (작성 중)

## 증거 메모 (Ep0)
- E0-1 두루마리에 이름이 적혀 있다(副提學 崔萬理) → T0a 는 이름표 읽기.
- E0-2 최만리 카드 + 그가 소리 내어 읽는 상소 = 「근거가 이 사람을 가리키지 않는다」(참인 근거를 거부).
- E0-3 세종 카드는 최만리 카드 속 「1419년(세종 1)」 링크로만 얻는다. 높은 자리 사람 = 군상 → 유일한 임금 카드.
- E0-4 역사 고정 칸 하나, 보기 3개(최만리/세종/상소한 사람들), 「최만리가 … 만리 등에게 이르기를」 자기모순.
