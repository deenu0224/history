## v3 요약
- 게임 전체는 연구원의 컴퓨터 화면 「결록 단말」(영화 〈서치〉 방식). 캐릭터 이동 없음.
- 나는 기록대조과의 **대조관 07**. 기록이 가리키는 과거를 보고 **일치/불일치** 도장을 찍는다.
- 앱 4개: **업무**(배정함·체크리스트·보고서·종결된 보고서) · **관측** · **DB 검색** · **메신저**.
- 동사(한 번에 하나): 보기 → 엿듣기+캡처 → 스크럽 → 대조 판정 → 검색 → 보고서(4칸) → 도장(길게 누르기) = 복원.
- 튜토리얼 말풍선·코치마크 0개. 막힘 힌트는 메신저로만.
- 모바일: 탭·끌기·핀치만으로 완주. 터치 영역 44×44 CSS px 이상. 같은 코드, 레이아웃만 다름(모바일 전체 화면 앱 + 하단 독 / 데스크톱 창).
