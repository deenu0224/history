# QA — 사용성·조작 (2026-10-17)

대상: 빌드 `8efd981`(로컬 `vite preview`), Ep0 「하룻밤」 → Ep1 끝까지. Playwright chromium, `isMobile + hasTouch`, 390×844 와 360×740. 탭은 `locator.tap()`(터치), 밀기·길게 누르기는 CDP 터치 이벤트(실제 손가락과 같은 pointer 흐름). 처음 하는 사람의 눈으로 정답 경로 + 일부러 틀리기·건너뛰기·가장자리 밀기를 섞었다. 화면마다 자동 감사(44px 미만 탭 대상, 위 1/3 의 버튼, 가로 넘침, 잘림, 알림과 탭 대상 겹침).

## 판정

**조건부 통과.** 큰 흐름(넘기기 → 이름 붙이기 → 그날의 방 → 모순 → 역사 고정 → 복원)은 두 폭 모두 끝까지 막힘 없이 간다. 가로 넘침 0, 회전 안내·움직임 줄이기·가장자리 밀기 뒤로(10px 시작)·컷 밀기(30px 시작은 컷 이전으로)는 모두 맞게 동작했다. 오답은 공짜이고 한 줄 피드백이 바로 뜬다.
다만 **터치에서만 드러나는 결함 하나(길게 누르기 뒤 손을 떼면 「기록이 돌아왔다 ›」가 같이 눌림)** 와 **「같은 사람 잇기」의 발견성**, **알림이 머리글·탭 대상을 덮는 문제**는 고친 뒤 실기기 확인이 필요하다. e2e(`v5.spec.ts`)는 길게 누르기를 마우스로 해서 1번을 잡지 못한다.

## 고칠 것 Top 5

1. **길게 누르기 뒤 손 떼기 클릭 관통** — 「기록이 돌아왔다 ›」가 저절로 눌려 복원의 순간을 건너뛴다. 완료 직후 클릭 무시 + 터치 e2e. (ux-01)
2. **「같은 사람 잇기」 발견성** — A 다음 B 를 바로 탭하면 잇기를 시도하도록. 지금은 조용히 선택만 바뀐다. (ux-03)
3. **알림 자리** — 메신저 배너가 머리글을, 모순 알림이 「⚠ 모순」 칩을, 「모두 밝혀졌다」가 역사 고정 빈칸·X2 범례를 덮는다. 탭 대상과 머리글이 없는 띠로. (ux-05~08)
4. **방 표시 겹침·크기** — 이어야 할 두 ? 가 포개지고 38~42px. 중심 간격·탭 영역 44 이상. (ux-04)
5. **X2 같은 값 세 번 + 홀드 짧은 탭 무반응** — 고른 값을 방·칸에 이어 주고, 짧은 탭엔 「길게 누르고 있어 줘」 한 줄. (ux-08, ux-02)
