# 낱말 감사 — 에피소드 0·1 (2026-10-15)

플레이어가 보는 모든 글(UI 라벨·메신저·카드 사실·본 것·컷 대사·다시 쓰기 조각·복원·홈·콜드 오픈)에서 지금 한국어 사용자가 잘 쓰지 않거나 알아듣기 어려운 말을 찾아 처리했다.

## 원칙

- **우리가 쓴 글**(reconstructed·fictional: 메시지·힌트·본 것·조각 이름·사람 이름표·방 이름·UI): 지금 말로 **바꿈**.
- **검증된 국역 인용**(verified: 컷 대사·카드 사실·기록·복원 전문·홈 단락·다시 쓰기 줄): 글자는 **유지**, 어려운 말에 **풀이**(점선 밑줄, 탭하면 바로 뒤에 20자 이내 풀이). 사전 `src/data/glossary.ts` 의 `GLOSSARY0`·`GLOSSARY1` → `Episode.glossary`, 화면 `src/ui/parts/GlossText.tsx`(말풍선은 대사의 `glosses` + 사전).
- 빽빽한 카드 인용 위에는 **쉬운 한 줄**(`Fact.plain`, 우리가 쓴 풀어 말하기 — 인용이 아니다)을 굵게 단다. 새 사실을 더하지 않는다(인용이 말한 것만).
- **찾기 낱말**(실선 + 옅은 바탕, 탭하면 풀이 + 「찾기」)은 에피소드 데이터가 정한 퍼즐 찾기어만: Ep1 「김일손」(1-4 대사·꾸러미 이름표)·「윤」(2-1)·「국장 도감」(3-1). 나머지 어려운 말은 풀이만(찾기 단추 없음). Ep0 엔 찾기가 없다(찾기 밑줄 0).
- 검증기 규칙 `words`(`src/core/validate.ts`): 찾기 밑줄은 찾기 데이터(`Episode.search`)에 있는 말만 · 찾기 없는 에피소드엔 찾기 밑줄 없음 · 대사의 풀이 낱말은 그 글 안에 있음 · 사전 풀이는 비어 있지 않고 20자 이내.
- SF 말은 「관측기」 하나(좌표·재계산·DB·동기화·탐지·로그 → 바꿈).
