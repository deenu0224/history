# UI STYLE GUIDE — 결록 v5

> 설계 원천: `DESIGN_V5.md`. 대사·메신저 타이밍: `DIALOGUE_GUIDE.md`. 픽셀 규격·팔레트: `ART_DIRECTION.md`.
> 상태: **목업 승인 대기.** 이 문서의 와이어프레임을 바탕으로 화면별 목업(정적 HTML 또는 이미지)을 만들어 사용자 승인을 받은 뒤에만 구현한다.

## 0. 원칙

1. **세로 전용.** 설계·테스트 폭은 360~430px(기준 390×844). 휴대폰을 가로로 돌리면 레이아웃 대신 「세로로 돌려 주세요」 화면(§2.12). 데스크톱은 같은 세로 화면을 가운데에 최대 폭 480px, 높이 100dvh(최대 932px)로 띄우고 바깥은 어두운 배경(`--backdrop`). 가로 레이아웃은 만들지 않는다.
2. **한 화면 = 한 초점.** 화면마다 주요 버튼은 **최대 3개**. 이동은 **아래 막대 3칸**(§2.0) — 위쪽에 뒤로 버튼을 두지 않는다(머리글은 제목·시각만). 설정·시트 닫기(✕)만 작은 아이콘으로 위에.
3. **주요 동작은 화면 아래 1/3**(엄지 영역). 위쪽 2/3 은 보는 곳.
4. **시각 언어는 둘뿐.** 현대 = 차갑고 어두운 단말(남색·숯·청록, 가는 선). 과거 = 따뜻한 픽셀 컷(한지·나무·먹·등잔빛). 섞지 않는다. 경계는 연출(어두워짐·소리 변화)로 넘는다. 예외 하나: 역사 고정의 **한지**(과거의 재료 위에 현대의 내가 쓴다 — 결말의 의미).
5. **화면 속 물건처럼(diegetic).** 인물 카드는 카드처럼(모서리·종이결), 방은 도면처럼(선·치수), 기록은 한지처럼. 버튼 대신 물건을 만진다.
6. **팝업 튜토리얼 없음.** 모달 설명·코치마크 0개. 첫 탭 하나만 은은히 강조(홈의 [관측하기]).
7. **글자 ≥16px, 위계는 세 단계뿐.** 터치 영역 ≥44×44px. 안전 영역(`env(safe-area-inset-*)`)을 늘 지킨다.

## 2. 와이어프레임 (세로 390×844 기준, 폭 360~430 에서 유동)

### 2.0 아래 막대 3칸 · 뒤로 (2026-10-15, 실기기 플레이테스트 반영)
```
├──────────────────────────────┤
│  ‹      [  이 화면의 주요 ] 💬• │  높이 56(+ 안전 영역은 틀이 이미 비운다), 양 칸 64×52, 가운데 버튼 높이 44
│ 뒤로    [      동작       ] 메신저│
└──────────────────────────────┘
```
- 하위 화면 모두(뷰어 · 메신저 · 찾기 · 인물 카드 · 역사 고정 · 설정 · 그날의 방 시트)에 같은 자리: **[‹ 뒤로] [주요 동작] [메신저(안 읽음 점)]**. 주요 동작이 없으면 가운데는 빈칸, 메신저 화면·「이 사람으로」를 고르는 카드에선 오른쪽 칸이 빈칸. 위쪽 뒤로 버튼은 없다 — 머리글은 제목·시각(뷰어는 + 「이름 붙이기 n/m」)만, 세로 공간을 컷에 준다.
- 화면별 가운데 칸: 뷰어 = 「역사 고정 ›」(쓸 수 있게 되면) > 「그날의 방」(열렸으면) > 「지금까지 본 것」, 나머지는 점 줄 양옆의 작은 아이콘(44px). 메신저 = 「어디부터 볼까요?」. 인물 카드(고르는 중) = 「이 사람으로」. 역사 고정 = 「길게 눌러 역사 고정」 → 100% 면 「기록이 돌아왔다 ›」. 그날의 방 = 「판단과 근거를 고른다/…를 남긴다」·「그날의 방으로」. 찾기·설정 = 빈칸.
- 홈은 독 3칸 [관측기] [찾기] [메신저](Ep0 은 찾기 없이 2칸).
- **왼쪽 가장자리 밀기 = 뒤로**(iOS 식): 화면 왼쪽 24px 안에서 시작해 64px 넘게 거의 수평으로 밀면 뒤로. 손가락을 따라 작은 「‹」 가 나온다. 뷰어의 컷 넘기기는 가장자리에서 시작한 밀기를 받지 않는다. 뒤로의 순서: 인물 카드 → 문서 → 지금까지 본 것 → 그날의 방 → 이름 붙이기 시트 → 화면(찾기에서 시트로 왔으면 시트로). 홈·복원 장면에선 아무 일 없음.
- 메신저 칸은 어디서든 떠 있는 카드·시트를 닫고 대화창으로 간다.

표기: `[ ]` 버튼, `( )` 칩/탭 가능한 것, `▓` 컷 이미지, `···` 안전 영역.

### 2.1 부트 / 프롤로그
```
┌──────────────────────────────┐
│···· 상태 표시줄 ··············│
│                              │
│                              │
│   언제부터인지, 역사가        │  ← Body 17, 줄간 1.7
│   사라지기 시작했다.          │     한 줄씩 페이드(600ms)
│                              │
│                              │
│                              │
│                    3 / 8     │  Meta 16, muted
│                              │
│  [ 건너뛰기 ]      [ 다음 ▸ ] │  아래 1/3, 화면 탭 = 다음
│··· 홈 인디케이터 ·············│
└──────────────────────────────┘
```
- 승인된 8줄 그대로. 소리: 'title' 트랙, 줄마다 종이 바람 아주 작게.
- 끝나면 콜드 오픈 두 줄(「23:04. 기록대조과. 야근.」 / 「모니터에 배정 하나. 우선순위 낮음.」) → 홈.

### 2.2 단말 홈
```
┌──────────────────────────────┐
│ 23:04   결록 단말        ⚙    │  Meta 16 / 설정 아이콘 44px
├──────────────────────────────┤
│ ┌──────────────────────────┐ │
│ │ 빈자리 #C-2217           │ │  Heading 22
│ │ 일시 ####                │ │  Body 17, 고정폭 숫자
│ │ 장소 미확인              │ │
│ │──────────────────────────│ │
│ │ 이 날의 기록이 비어 있다.│ │
│ │ 그날 그 자리에 있던      │ │
│ │ 사람들의 눈으로 본다.    │ │
│ │──────────────────────────│ │
│ │ 열린 눈  ◉ ○ ○ ○ ┄       │ │  눈 아이콘 24px(§5)
│ └──────────────────────────┘ │
│                              │
│                              │
│      [   관측하기   ]       │  주요 버튼 1(높이 56, 첫 탭 강조)
│                              │
├──────────────────────────────┤
│  (관측기) (찾기)   (메신저•) │  독, 각 칸 ≥ 64×56
└──────────────────────────────┘
```
- 카드 안 진행 두 가지: **「그날 고정률 NN%」**(얇은 막대 하나, 하루 전체 — 꼭 돌아와야 할 실록 문장 중 고정된 비율, 데이터에서 계산; 길게 눌러 역사 고정한 뒤에만 오르며 숫자가 차오른다, 100% = 그날이 굳음) · 눈 줄 아래 **「이름 붙이기 n/m」**(m = `Episode.requiredTags` 수 — 목표 수일 뿐 답이 아니다, 다 붙이면 호박색 「· 모두 밝혀졌다」, 남은 모순이 있으면 「· 남은 모순 1」). 줄마다·칸마다의 수치는 어디에도 없다.
- 역사 고정을 열 수 있게 되면 **[역사 고정 ›] 이 맨 위 주요(숨쉬는 강조)**, [관측하기] 는 보조로 내려간다.
- 고정 뒤: 카드가 「고정됨」(일시·장소 채움, 돌아온 줄 두 줄, 이웃 기록 한 줄, 「전문 펼치기」)으로 바뀌고 보조 [고정된 기록]. 홈 알림은 카드 머리 쪽(아래 버튼을 가리지 않는다).

### 2.3 컷 뷰어 — 관측
```
┌──────────────────────────────┐
│ 첫 번째 관측 (이름 붙이기 1/4) 14:00│  위 띠 48px(반투명 숯), 뒤로 버튼 없음. 이름은 태그 뒤에만. 진행 칩(다 붙이면 호박색)
│ ◉ ◉ ○ ○ ┄                    │  눈 줄(현재 눈 밝게) — 눈이 둘 이상일 때만(하나면 줄을 두지 않고 컷이 위 띠 바로 밑에 붙는다)
├──────────────────────────────┤
│▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▏ ← 다음 컷 가장자리 8px
│▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▏
│▓▓▓▓▓▓▓▓  ( ? )  ▓▓▓▓▓▓▓▓▓▓▓▓▓▏ 사람: 탭 영역 ≥44, 숨쉬는 테두리 1회
│▓▓▓▓▓┌──────────────────┐▓▓▓▓▏
│▓▓▓▓▓│ 김일손(金馹孫)의  │▓▓▓▓▏ 말풍선: Body 17, 한지색 바탕
│▓▓▓▓▓│ 사초(史草)를 모두│▓▓▓▓▏ 점선 = 어려운 말(탭 → 짧은 풀이만)
│▓▓▓▓▓│ 대내(大內)로     │▓▓▓▓▏ 실선+옅은 바탕 = 찾기 낱말(데이터의 퍼즐 찾기어만)
│▓▓▓▓▓│ 들여오라.        │▓▓▓▓▏
│▓▓▓▓▓└──────────────────┘▓▓▓▓▏
│▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▏
│▓▓▓▓ 소매(앞쪽 덮개) ▓▓▓▓▓▓▓▓▓▓▏ 컷은 화면 폭 가득, 정수 배율
├──────────────────────────────┤
│ ▤   ‹ ● ● ● ○ ○ ›   ▦        │  컷 위치 점 + 양옆 작은 아이콘(지금까지 본 것 · 그날의 방 — 가운데 칸이 아닐 때)
│ ‹뒤로 [  그날의 방  ] 메신저• │  아래 막대(§2.0). 가운데 = 역사 고정 › > 그날의 방 > 지금까지 본 것
└──────────────────────────────┘
```
- 컷 영역: 폭 100%, 높이 = 화면 − 위 띠 − 아래 영역(최소 420px). 픽셀은 정수 배율, 남는 공간은 비네트로 채움(늘이지 않음).
- 밀기: 손가락을 따라 움직이고 30% 넘거나 빠르게 튕기면 넘어감(220ms ease-out). 마지막 컷에서 더 밀면 고무줄 + 아무 일 없음.
- 말풍선은 컷에 들어가면 차례로 자동 표시(문자 수 × 35ms 뒤 다음), 컷의 빈 곳을 탭하면 즉시 다음. **한 번에 하나**(가장 최근 말), **세 줄까지** — 넘치면 「…더 보기」로 펼친다.
- 말풍선 자리: 컷 아래 남는 자리가 100px 이상이면 **컷 밖(아래)**에(2~3줄), 아니면 컷 위·아래 띠 중 사람·세부 상자(이름표 포함, manifest 상자로 계산)를 덜 가리는 쪽. 말풍선은 **탭을 통과시킨다** — 밑의 사람·세부가 눌린다(안의 낱말·「더 보기」만 눌림).
- 알림(「인물 카드 +1」 등)은 머리글(제목·이름)을 가리지 않는다: 기본은 아래쪽, 뷰어에서는 위 띠 바로 밑, 인물 카드 위에서는 화면 맨 아래.
- 끊긴 관측의 안 본 컷: 컷 자리에 차가운 회색 판 「볼 수 없다 — 이 사람의 그날 기록이 지워졌다」.

### 2.4 이름 붙이기 시트
```
┌──────────────────────────────┐
│▓▓▓▓▓ 컷(위 40%, 고른 사람 밝게) ▓│
│▓▓▓▓▓▓▓▓▓▓▓▓▓( ? )▓▓▓▓▓▓▓▓▓▓▓▓│
├──────────── ━━━ ─────────────┤  시트 손잡이
│ 이 사람은 누구인가           │  Heading 22
│ ① 카드                       │  Meta 16
│ ┌─────┐┌─────┐┌─────┐ ›     │  카드 가로 목록(각 112×148, 이 방 카드 먼저)
│ │이극돈││어세겸││신승선│       │
│ │李克墩││魚世謙││愼承善│       │
│ └─────┘└─────┘└─────┘       │
│ ② 근거 하나                  │
│ ┌──────────────────────────┐ │  카드 고른 뒤 열림. 근거 행 높이 ≥56
│ │ 「저 대감께선 선왕 승하  │ │  이 사람이 나온 컷의 것이 위
│ │  실록 때도…」  11:40      │ │
│ ├──────────────────────────┤ │
│ │ 「오늘 들어온 꾸러미…」  │ │
│ └──────────────────────────┘ │
└──────────────────────────────┘
```
- 단계: 카드 탭 → (카드가 살짝 올라감) 근거 목록 열림 → 근거 탭 → 즉시 판정. 주요 동작은 두 번의 탭뿐, 확인 버튼 없음(실패가 공짜이므로).
- 성공(헷갈리지 않게): 시트가 **도장 「이름 · 한자 · 이름 붙음」** 을 찍고 내려간다(1.1s) → 컷 속 그 사람 위 **이름표가 호박색으로 한 번 튄다**(2.4s 뒤 보통 이름표) → 소리·진동 `tag_ok` → 머리의 「이름 붙이기 n/m」 이 오른다. 눈이 열리면 §4 눈 열림 연출.
- **마지막 필수 이름**: 알림 「모두 밝혀졌다」 + 작은 소리 `tags_done`(눈 열림 알림이 같이 뜨면 그 뒤에) · 진행 칩 호박색 · 역사 고정을 열 수 있으면 뷰어 아래 가운데 칸이 **「역사 고정 ›」**(누르면 바로 역사 고정 화면), 홈 주요도 「역사 고정 ›」. 한 선임 한 줄(Ep0 「이제 고정해 봐.」). Ep1 은 마지막 이름 뒤에도 닫힘·모순이 남아 가운데 칸은 그날의 방 — 쓸 수 있게 되면 바뀐다.
- 실패: 시트 안에 한 줄(Body 17, 모순은 `--alert`): 「근거가 이 사람을 가리키지 않는다」 등. 시트 유지, 고른 것 해제. 진동 없음, 소리 `tag_no`(낮고 짧게).
- 카드 길게 누르기 = 인물 카드 전체 보기(§2.5).

### 2.9 역사 고정 (옛 이름 기록 다시 쓰기, 내부 rewrite)
```
┌──────────────────────────────┐
│ ‹  빈자리 #C-2217            │
│ ┌──────────────────────────┐ │  한지(#efe5cb), 종이결
│ │ 14:00                    │ │  줄마다 시각(Meta 16, 갈색)
│ │ 전교하기를, "[김일손]의  │ │  칸 = 점선 상자, 탭 → 값 시트
│ │ 사초를 [ 모두 ] 대내로   │ │  본문 Serif Body 18
│ │ 들여오라."               │ │
│ │                          │ │
│ │ 14:05                    │ │
│ │ ([당상(이극돈 등)]) "예로부터 …"  │ │
│ │                          │ │
│ │ 15:00                    │ │
│ │ [이극돈] 등이 [일손]의   │ │
│ │ 사초에서 [ ⚠ ]조목을 …   │ │  ⚠ 칸 탭 → 그날의 방 모순 보기
│ └──────────────────────────┘ │
│ [ 고정할 문장 더하기 ]       │  보조(조각이 있을 때만)
│ ‹뒤로 [길게 눌러 역사 고정] 💬│  아래 막대 가운데, 1.2초 길게 누르기
└──────────────────────────────┘
```
- 칸 값 시트: 내가 확인한 값만, 행 높이 ≥56. 값 옆에 어디서 봤는지(컷 번호).
- 머리: 「빈자리 #C-…」(뒤로 버튼 없음) 바로 아래 **「그날 고정률 NN%」** 얇은 막대(청록 → 100% 호박). 길게 눌러 역사 고정한 뒤에만 오른다(1.1s 차오름).
- 판정 뒤: 고정된 문장은 먹이 번지며 국역으로 굳고 아래 출처 한 줄(Meta 16). 회색 줄(증인만 본 것)은 `--ink-witness` + 점선 밑줄 + 끝에 「실록이 적지 않은 일」. 실록과 안 맞은 문장은 **흐릿하게 깜빡이며 「흐릿함 — 그날에 붙지 않았다」**, 고정률에 세지 않는다(어느 칸이 틀렸는지는 말하지 않는다).
- **복원의 순간은 이 화면 안에서**(고정률 100%): 칸이 그 자리에서 먹으로 채워지는 한 번의 연출(흐림 → 호박 밑줄, 1.3s) + 출처 한 줄이 따라 나오고, 소리 `restore`, 머리에 「고정됨」, 아래 가운데 칸은 하나 — **「기록이 돌아왔다 ›」**(→ §2.10).

### 2.10 복원 — 세 박자 (2026-10-15 압축)
같은 단락을 여러 번 보이던 단계(기사 · 홈 · 이웃 기록)를 줄였다. 복원의 순간은 이미 역사 고정 화면 안에서 지나갔다(§2.9).
```
┌──────────────────────────────┐
│ 1 / 3                        │
│ ┌──────────────────────────┐ │  ① 빈자리 카드가 뒤집힌다(0.9s) → 「고정됨」
│ │ #C-2209           고정됨 │ │
│ │ 일시  세종 26년 2월 20일 │ │  일시·장소 먹 번짐
│ │ 그날 실록 「[임금이] 소… │ │  돌아온 줄: 두 줄, 채운 「누가」 칸만 밝게
│ │ 이웃 기록도 함께 돌아왔다│ │  이웃 기록: 같은 카드 안 한 줄 + 꼬리표 한 줄
│ │ 그날 고정률 100% ━━━━━━━ │ │
│ │      전문 펼치기 ▾       │ │  전문(한지·인장·출처)은 여기서만 펼친다
│ └──────────────────────────┘ │
│            [ 다음 ▸ ]        │  주요 1
└──────────────────────────────┘
```
- 단계(`Episode.restoreSteps`): **Ep0** `home → monologue → bridge`(다리 = 보통 대화창, 시계 23:04 → Ep1 콜드 오픈). **Ep1** `home → cards → monologue → teaser`. Ep1 의 「바뀐 것」(`cards`)은 새 정보만 한 화면에: 인물 카드에서 바뀐 줄(사인·파직·좌천, 출처) · 그날의 방 「?」 의 짝 이름 「유순·안침」 · 「내 관측 기록은 그대로 — 23:04 찾기 「대내로 들여오라」 → 실록에 없음」 한 줄. 옛 `article`·`neighbour`·`room`·`log` 단계는 없앴다(전문은 카드의 「전문 펼치기」, 홈 카드에서도 같은 버튼).
- 그날 기록이 통째로 지워진 날(Ep1, 홈 카드에 문장이 없다)은 카드에 「고정된 문장」 첫 줄을 두 줄로 + 「고정한 문장 5개가 모두 실록으로 돌아왔다」.
- ② 짧은 독백 한 화면 → ③ 다리(Ep0)/예고(Ep1).

- 대화의 현실 재기록은 복원 단계로 보여 주지 않는다(「메시지」 단계 없음, 표시·효과 없음). 복원 뒤 새 말은 보통 대화창에 온다(Ep0 다리 장면).
- 홈 카드의 빈자리: 길이가 다른 짧은 청록 밑줄 한 가지 모양(「누가」 칸만 작은 「?」). 글자 상자·점선 테두리를 쓰지 않는다.
- 인물 카드 줄: 빽빽한 인용 위에 쉬운 한 줄(굵게, 우리가 쓴 말), 아래 인용은 글자 그대로 조금 옅게 — 괄호 속 한자는 작고 옅게, 어려운 말은 점선(탭 → 풀이), 긴 줄은 두 줄로 접고 ▾ 로 펼친다. 줄 안의 인물 링크는 테두리·바탕이 있는 알약 + 「›」.
- 역사 고정 칸 값 시트에는 내부 컷 번호를 쓰지 않는다.

### 2.11 설정
항목(토글/선택, 각 행 ≥56): 소리 크기 · 음악 · 진동 · 힌트(끔/보통/자세히) · 글자 크기(기본/크게 = 모든 단계 +2px) · 움직임 줄이기 · 「이 장면에 대해」(재구성 안내) · 저장 지우기(두 번 확인).

- 글꼴: 현대 UI = 시스템 고딕(Pretendard 가 있으면 우선), 실록 인용·한지 = 명조 계열(`--f-read`), 픽셀 장식(눈 아이콘·시각 숫자) = 기존 `--f-pixel` 은 제목 장식에만 — 본문에 쓰지 않는다.
- 숫자는 고정폭(`font-variant-numeric: tabular-nums`). 한자는 괄호 안, 같은 크기.
- 설정 「크게」: 모든 단계 +2px, 레이아웃은 줄바꿈으로 흡수(가로 스크롤 금지).

## 7. 진동과 소리

진동은 `navigator.vibrate`(안드로이드 크롬). **iOS 사파리는 웹 진동을 지원하지 않는다** → 같은 순간에 소리 + 시각 피드백이 늘 함께 있어야 한다. 첫 사용자 제스처 전에는 울리지 않는다(기존 규칙). 설정에서 끔.

| 순간 | 진동(ms) | 효과음(이름) | 음악 |
|---|---|---|---|
| 컷 넘김 | — | `swipe`(종이, 아주 작게) | 'observe' |
| 이름 붙이기 성공 | [18] | `tag_ok`(붓 끝 + 맑은 한 음) | — |
| 이름 붙이기 실패 | — | `tag_no`(낮고 짧은 나무) | — |
| 눈 열림 | [20, 40, 20] | `eye_open`(현 하나, 거문고 낮은 음) | — |
| 겹침 | [10] | `merge` | — |
| 모순 드러남 | — | `hear`(짧은 불협) | 'tension' 으로 교차 |
| 모순 해소 | [12] | `resolve` | 'observe' |
| 눈 닫힘 | — | 무음(환경음도 0.8s 끊김) | 'tension' 잦아듦 |
| 메시지 도착 | — | `message` | — |
| 줄이 기록이 됨 | [15] 줄마다 | `write`(먹 스밈) | — |
| 현실 재기록 | [30, 60, 30, 60, 80] | `restore`(기존) | 'restore' → 에필로그 'ending' |

기존 `SFX_NAMES` 에 없는 이름(`swipe, tag_ok, tag_no, eye_open, merge, resolve, write`)은 오디오 모듈에 추가하고 `SFX_ALIASES` 로 기존 소리에 임시 연결할 수 있다(`tag_ok→success`, `tag_no→fail`, `merge→select`, `resolve→partial`, `write→page`, `eye_open→discover`, `swipe→page`).

## 8. 접근성

- 대비: 본문 ≥4.5:1(위 토큰 모두 충족), 큰 글·아이콘 ≥3:1. 색만으로 뜻을 전하지 않는다: 모순 = ⚠ 기호 + 문구, 회색 줄 = 점선 밑줄 + 끝말, 닫힌 눈 = 모양이 다름.
- 터치 ≥44px, 주요 버튼 높이 56. 길게 누르기(1.2s)는 설정에서 '두 번 탭'으로 바꿀 수 있다.
- 시간 압박 없음(실시간 타이머 없음). 메신저 말풍선은 자동 사라지지 않는다.
- 화면 읽기: 컷마다 대체 텍스트(「서안 너머 붉은 관복의 관원이 종이 한 장을 들고 있다. 뒤에서 귓속말이 들린다.」), 사람은 버튼(「모르는 사람, 서안 너머」), 도면은 목록 대체(「14:00 · 홍귀달의 눈: 문에서 5.7칸, 들림」). 대체 텍스트도 연도·장소·이름을 말하지 않는다(태그 전).
- `prefers-reduced-motion` = 설정 「움직임 줄이기」 기본값.
- 글자 크기 「크게」, 줄바꿈으로 흡수.
- 포커스 링 `--accent-strong` 2px(키보드, 데스크톱 프레임).

## 9. 모바일·성능·PWA

- 세로 고정: 매니페스트 `"orientation": "portrait"`, `"display": "standalone"`. 설치 전 브라우저나 iOS 처럼 고정이 안 되는 곳은 §2.12 화면으로 처리.
- 안전 영역: 위 띠와 아래 버튼 영역에 `env(safe-area-inset-top/bottom)` 패딩. 높이 단위는 `dvh`.
- **첫 로드 < 3초**(중급 안드로이드, 빠른 4G): 첫 화면 JS ≤ 250KB(gzip), Phaser 를 번들에서 뺀다. 컷은 코드 정의 픽셀 아트를 캔버스로 한 번 그려 `ImageBitmap`/PNG Blob 으로 캐시(Cache Storage). 첫 관측의 첫 컷만 먼저, 나머지는 유휴 시간에. 컷 한 장 그리기 ≤ 30ms 목표.
- 오프라인: 서비스 워커가 앱 셸·글꼴·오디오 합성 코드를 미리 저장. 외부 요청 없음(출처 URL 은 사용자가 탭할 때만 새 창).
- 홈 화면에 추가: 아이콘 192/512(픽셀 눈 아이콘), 스플래시 `--bg`.
- 저장: 매 행동 IndexedDB, 저장점 5개(DESIGN_V5 §2.7). `visibilitychange` 숨김 때 즉시 저장, 오디오 정지.
- 끌기 없음: 이름 붙이기·다시 쓰기·방은 모두 탭. 밀기는 컷 넘기기와 시트 내리기뿐.
