### 3.1 바로 이어지는 것
- 에피소드 1 끝: 종결함에 07의 '관측 오류' 2건(#C-0408, #C-3391). 에피소드 2 첫 화면의 배정함 5번째가 **#C-0408 · 재배정(이전 판정 있음)**.
- 07은 무오사화가 '없던' 세계를 기억한다(복원을 직접 봄). 한 선임은 "늘 알던 일"로 기억한다. 이 비대칭이 이번 근무 내내 깔린다.

## 4. 새 메커니즘 — 겹쳐 보기(하나)

### 4.1 규칙
- 관측 화면에 「겹치기」 버튼. 누르면 **이 근무에서 본 관측**과 **보존 프레임**의 썸네일 목록(장소 이름 없음, 건 번호와 시각만).
- 하나를 고르면 화면 가운데 세로 **봉합선**이 생긴다. 봉합선 왼쪽은 지금 보는 날, 오른쪽은 고른 날. 봉합선을 끌어(손가락 하나, 손잡이 44px 이상) 두 날을 닦아 보듯 오간다.
- **같은 장소**면 바위·지붕선이 딱 맞물리며 작은 '딱' 소리와 먹 번짐 한 번. **다른 장소**면 아무것도 맞지 않고 "겹치는 곳이 없다." 한 줄(벌 없음 — 실패해도 손해 없는 실험).
- 봉합선이 지나가는 자리에서 **한쪽 날에만 있는 것**(핫스팟)에 가는 먹선이 선다. 정답 표시는 아니다 — 다르다는 것만.
- 시간 막대는 지금 보는 날에만 작동한다. 고른 날은 그 관측의 같은 시각(관측일 때) 또는 그 프레임의 시각(프레임일 때)에 고정.
- 겹친 채 셔터 → **겹친 프레임**(필름 1칸, 두 날의 스냅숏 + 차이 목록). 증거로 붙일 수 있다.
- 사찬 카드(『임계기사』 요지)는 **새 규칙이 아니다**: 출처 표기만 다른 기록 카드다. 도장·검사 모드가 똑같이 작동한다(§14 개선 1회).

### 4.3 데이터 계약(구현자용 제안, `src/` 미변경)
```ts
type OverlaySource = { kind: 'observation'; obsId: string } | { kind: 'frame'; frameId: string };
startOverlay(src: OverlaySource): void;   // 관측 화면에서만
setSeam(x01: number): void;               // 0..1, 뷰어 좌표
endOverlay(): void;
// 겹친 채 captureFrame(snapshot) → Frame.overlay?: {
//   other: ViewerSnapshot; samePlace: boolean;
//   onlyNow: HotspotId[]; onlyOther: HotspotId[] }
```
- 같은 장소 판정: 관측 데이터의 `placeId` 일치(플레이어에게 placeId는 보이지 않는다).
- 단서는 기존처럼 데이터로 계산: `clues.ts`의 조합 단서가 `overlay: { samePlace: true, onlyNow: [...], onlyOther: [...] }` 조건을 가질 수 있게 한다. UI에 정답 하드코딩 없음.
- 아트: 같은 디오라마의 날별 변형(소품·NPC 배치만 다름)을 재사용 → 겹침이 정확히 맞물린다(§8).
