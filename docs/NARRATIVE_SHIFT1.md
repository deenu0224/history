# 근무 1 소설 시안 v2.1 (사용자 승인 v2 · 사료 정정 반영 · v4 「근무」 기준 레퍼런스)

페이퍼 플리즈식 근무 구조. 구현은 이 흐름·정보 공개 순서·톤을 따른다.
v2 → v2.1: 승인된 흐름·순서·톤은 그대로 두고, 기록 카드 문장과 관측 대사를 `HISTORICAL_SOURCES.md` §10.1 의 검증 결과에 맞췄다(정정 목록은 맨 아래).

## 규칙
- 판정 도장 2개: **확인**(초록, 실록 문장 = 관측) / **정정**(파랑, 실록 문장의 일부가 관측과 다름 → 다른 낱말을 짚으면 검증된 원문으로 복원).
- 세 번째 도장 **불일치**(빨강)는 서랍 속, 규정 외. 기록이 아예 없는 건(소실)에만 의미가 있다. 쓰면 경고.
- 모든 도장 자국 아래 작은 각인 `07`. 손잡이에도 07.
- 검사 모드: 기록 카드의 낱말과 관측(대사·장면)의 대상을 차례로 탭 → 빨간 실(다름) / 노란 깜빡임 후 끊김(표기 차이, 판단은 대조관) / 연결 없음(같음).
- 처리 목표 5건. 오판 시 빨간 경고장이 프린터에서 나온다. 3회 누적 시 관측 권한 정지(게임 오버 아님 — 면담 장면 후 계속).
- 왜곡(낱말이 바뀜) = 일상 업무, 시스템이 고칠 수 있음. 소실(기록 자체가 없음) = 시스템이 알아보지 못함 → '장비 오류로 자동 종결'.

## 흐름
1. 23:04 로그인 "대조관 07". 근무 명세(목표 5건, 확인/정정 설명 1줄씩). 책상 위 도장 둘(손잡이 07).
2. 건 1 #A-0412 (확인): 『성종실록』 성종 25년 12월 24일 「오시(午時)에 임금이 대조전(大造殿)에서 훙(薨)하였다.」(낱말 '훙'·'오시'를 누르면 풀이) ↔ 관측: 겨울 궁궐 안채, 내관 「…대조전에서… 상께서 승하하셨소.」, 한낮 → [확인], 자국 아래 07.
3. 건 2 #A-0419 (정정, 첫 검사 모드): 『연산군일기』 연산 1년 4월 19일 기록이 「왕이 어세겸(魚世謙)·유자광(柳子光) 등에게 명하여 (대행왕의 《실록》을) 편찬하게 하였다.」(변조) ↔ 관측 대사 「…어세겸과 이극돈은 대행왕의 실록을 편찬하라.」 → 두 낱말 탭 → 빨간 실 → [정정] → 원문 복원 「왕이 어세겸(魚世謙)·이극돈(李克墩) 등에게 명하여 (대행왕의 《실록》을) 편찬하게 하였다.」 ✓검증 출처 표시.
4. 건 3 #A-0423 (함정, 정답=확인): 『연산군일기』 연산 1년 1월 14일 「묘호(廟號)는 성(成)이라 하였다.」 ↔ 관측 「대행왕의 묘호는 성종으로 정하였소.」 → 검사 모드 노란 깜빡임 '표기 차이' → 플레이어가 [정정] 시 경고 1: "묘호 '성(成)'에 '종(宗)'을 붙여 부르는 이름이 '성종'이다. 같은 실록 기사도 '성종(成宗)'이라 쓴다. 같은 내용." → 깨달음: 묘호는 죽은 뒤 붙는 이름, 글자가 아니라 뜻을 비교.
5. 건 4 #A-0431 (정정): 『연산군일기』 연산 5년 [9월](변조) 10일 「《성종실록(成宗實錄)》이 완성되매, 수찬 당상·낭청에게 차등을 두어 물품을 사급(賜給)하였다.」 ↔ 관측: 인쇄를 마친 서책과 궤 곁에서 푸른 관복 「삼월 초열흘. 실록이 이루어졌으니, 수찬한 이들에게 상을 내리신다.」 → 날짜의 '9월'과 '삼월'을 짚음 → [정정] → 「3월 10일」 ✓검증.
6. 건 5 #C-2217 (붉은 테두리): 일시 #### · 장소 미확인(기록상: 『성종실록』 편찬 실록청) · 이 지점을 가리키는 기록 3건에서 자동 탐지 · **실록 기록: 없음** · 시스템 권장: 대조할 기록 없음 → 장비 오류로 자동 종결. 하루 전체 관측(시간 막대). 붉은 관복 「…이 글은 그대로 넘길 수 없소.」, 서리 「저 영감은 세조대왕 실록 때도 편수를 맡으셨다지.」(→ 건 2의 이극돈 연결), 14:00 전교 「김일손의 사초를 모두 대내로 들여오라.」, 당상들 「임금이 만약 사초를 보면 후세에 직필이 없기 때문입니다.」 → 확인/정정 불가 → 서랍의 세 번째 도장 **불일치**(도장 면에 마른 붉은 잉크) → 찍음(07) → 0.3초 뒤 회색 '관측 오류 · 종결' 덮임 → 경고 2(규정 외 도장) → 카드가 뒤집히며 **판정 이력**: 오늘 [불일치·07] / 1년 전 [불일치·07, 바랜 잉크] → 1년 전 도장 탭 → 확대, 07 → "나는 이 도장을 찍은 기억이 없다." → 오 실장: "07. 경고 두 개야." ## 톤
1인칭, 성별 중립, 짧은 문장. 튜토리얼 팝업 없음 — 근무 명세 1줄과 실수(경고)로 배운다. 실록 원문은 verified(출처), 관측 대사는 reconstructed, 변조된 기록 낱말은 fictional('변조' 표시).
