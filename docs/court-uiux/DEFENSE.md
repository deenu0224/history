## 1. 변론 요지

1. **그래픽은 장르 안에서 독자적이고 일관된 완성품이다.** 코드로 정의한 3D 방을 증인 눈높이로 렌더 → 제한 팔레트 양자화·Bayer 디더·입자·비네트 → 정수 배율 픽셀 컷. 한 장도 손그림·외부 이미지가 없고, 단말 UI와 컷이 같은 먹·한지·호박·청록 토큰을 쓴다.
2. **모바일 세로 전용 규칙을 실제로 지킨다.** 360·390·430 폭 모두 가로 스크롤 0, 컷은 3배 정수 배율, 가로로 돌리면 「세로로 돌려 주세요」만, 데스크톱은 세로 프레임 가운데 + 키보드 넘기기.
3. **한 화면 한 초점, 아래 막대 3칸, 팝업 튜토리얼 0.** 완주 중 모달 설명·코치마크를 한 번도 보지 않았다. 가르침은 실패 문구 한 줄과 한 선임 메신저뿐이다.
4. **피드백 연출이 촘촘하다.** 도장·이름표 튐·눈 열림·고정률 차오름·먹 번짐·짧게 누르기 안내·「단번에 맞힘」 — 성공·실패·보상마다 시각 신호가 있고 소리·진동이 짝을 이룬다.
5. **품질 보증 체계가 출시 팀 수준이다.** 1,338줄 e2e가 같은 완주를 실제 탭으로 돌며 탭 영역 ≥44, 막대 높이, 배너 겹침, 한글 읽기 누락을 숫자로 검사한다.

검사가 짚을 만한 결함(작은 글자 3곳, 떠 있는 배너가 읽을 글을 덮는 순간 2번, 문서와 어긋난 확인 버튼 등)은 **인정한다.** 모두 수정 비용이 1시간 이하이고, 출시 차단 사유가 아니다(§5 표).

## 2. 증거 목록

### 증거 1 — 증인 시점 픽셀 컷(그래픽의 중심)
- **한 일/본 것**: Ep0 컷 1(`p-07-ep0-viewer-1.png`): 하위지의 눈높이에서 본 대청. 앞쪽 아래에 내 초록 소매(앞쪽 덮개), 왼쪽 관원이 든 두루마리 「副提學 崔萬理」가 실제로 렌더되어 단서가 된다. 컷 3(`p-10-ep0-viewer-3.png`)은 붉은 곤룡포의 높은 자리 인물 클로즈업 — 얼굴은 코·수염만, 만화 눈 없음(ART_DIRECTION_V5 §5). Ep1 홍귀달의 눈(`p-49-ep1-viewer-closed-eye.png`): 구석 자리, 문빛 앞 먼 실루엣 — 「멀어서 흐리게 들렸다」가 화면 기하로 보인다.
- **재현**: 새 게임 → 「관측하기」.
- **왜 강점인가**: 「기록이 남은 사람의 눈으로만 본다」(CLAUDE.md 규칙 9)를 카메라 자체로 구현했다. 가림·거리가 판정 데이터와 같은 치수로 렌더된다(ART_DIRECTION_V5 §6·§7). 그래픽이 장식이 아니라 증거다.
- **코드**: `src/game/pov/` 19개 모듈 5,462줄(`hall.ts` 대청, `figure.ts` 사람, `post.ts`·`post-pixel.ts` 후처리, `palette.ts:7` `MOOD` 공유 토큰). `src/game/pov/bake.ts:1-4` — 개발 때 한 번 구워 WebP로 저장, 런타임은 three를 싣지 않는다. 결과물 `public/cuts/` 전체 956KB.

### 증거 2 — 정수 배율·일관된 팔레트
- **본 것**: 컷 `<img>`의 원본 폭 대 기기 픽셀 비율 — 390폭 **정확히 3.000**, 360폭 3.009, 430폭 3.007(CSS 1px 반올림 차이). `image-rendering: pixelated`(`src/styles/ui.css:559-566`).
- **재현**: 각 폭에서 뷰어 진입 후 `img.naturalWidth`와 `getBoundingClientRect().width × devicePixelRatio` 비교.
- **왜 강점인가**: 픽셀 아트의 기본 품질 기준(번짐 없는 정수 확대)을 세 폭 모두 충족. 팔레트는 기억 48색·지워진 기억 17색으로 닫혀 있고(ART_DIRECTION_V5 §2.1), 따뜻함=기억·복원, 청록=소실이라는 의미 규칙이 화면 전체에서 지켜진다(닫힌 눈 청록 가로줄 `p-49`, 빈자리 청록 밑줄 `p-05`, 복원 호박 `p-27`).

### 증거 3 — 세로 전용 대응
- **본 것**: 가로 844×390 → 화면 전체가 픽셀 회전 아이콘 + 「세로로 돌려 주세요」(`rot-01-landscape.png`). 다시 세로로 돌리면 프롤로그 그 자리로 복귀(`rot-02-back-portrait.png`). 360·390·430 모두 `scrollWidth − innerWidth = 0`.
- **데스크톱**: 1280×800에서 가운데 세로 프레임(폭 369px = 높이×9/19.5, 최대 480), 바깥 어두운 배경 + 비네트(`desk-02-viewer-arrow.png`). 키보드 → 로 컷이 넘어감(data-index 0→1).
- **코드**: `src/shell/orientation.ts:3` `(orientation: landscape) and (pointer: coarse)`, `src/shell/RotateGuard.tsx:31` 설치형에서 `screen.orientation.lock('portrait')`, `public/manifest.webmanifest:10-11` `standalone`·`portrait`, `src/shell/shell.css:32` `--app-w: min(480px, …)`.
- **왜 강점인가**: CLAUDE.md 규칙 8을 문자 그대로 충족. PWA 매니페스트·서비스 워커(`src/shell/registerSw.ts`)까지 갖춘 출시형 셸이다.

### 증거 4 — 화면당 초점 1개, 아래 막대 3칸
- **본 것**: 하위 화면 모두 아래에 「‹ 뒤로 / [주요 동작 하나] / 메신저」(`p-07`, `p-17`, `p-26`, `p-36`, `p-49`). 가운데 칸은 상황에 따라 하나만 바뀐다: 「지금까지 본 것」 → 「⚠ 그날의 방」(`p-49`) → 「역사 고정 ›」 → 「기록이 돌아왔다 ›」(`p-26`). 홈은 주요 버튼 하나 「관측하기」(`p-05`), 역사 고정이 열리면 그것이 위로 올라가고 관측하기는 보조로 내려감(`p-20`). 복원·예고 화면은 버튼 하나(`p-27`, `p-62`).
- **왜 강점인가**: 「다음에 뭘 하지?」를 화면이 하나의 버튼으로 답한다. 닌텐도식 「하나의 새 요소」(규칙 10)를 UI 구조로 보장한다. 위쪽 뒤로 버튼을 없애 세로 공간을 컷에 줬다.

### 증거 5 — 팝업 튜토리얼 0, 해 보며 배우기
- **본 것**: 완주 내내 모달·코치마크 없음. 첫 이름 붙이기에서 미끼 카드(정창손)를 고르면 시트 안 한 줄 「근거가 이 사람을 가리키지 않는다」, 시트 유지, 손해 없음(`p-14-ep0-tag-fail.png`). 역사 고정 버튼을 짧게 누르면 「길게 누르세요」가 숨쉬고 빈칸이 깜빡(`p-23-ep0-short-press-hint.png`). 틀린 값으로 고정하면 「흐릿함 — 그날에 붙지 않았다」, 고정률 0% 유지(`p-24-ep0-rewrite-miss.png`). Ep1 T3에서 「그 말이 이 사람 얘기인지 아직 모른다」 → 「이 시각, 그날의 방」 링크가 다음 할 일을 가리킨다(`p-38-ep1-not-linked.png`).
- **왜 강점인가**: 실패가 공짜이고 실패 문구가 곧 튜토리얼이다(규칙 9·10). 힌트는 한 선임 메신저에서만, 플레이어가 「어디부터 볼까요?」로 먼저 물을 때 온다(`p-12-ep0-messenger.png`).

### 증거 6 — 피드백·보상 연출
- **본 것**: 정답 이름 붙이기 → 도장 「최만리 · 崔萬理」가 찍히며 시트가 내려가고(`p-15`), 컷 속 그 사람 위 「?」가 호박색 이름표 「최만리」로 바뀌고 진행 칩 1/2(`p-16`). T4를 단번에 맞히면 도장 아래 「단번에 맞힘」이 한 번 더 찍힌다(내 캡처 `p-43`은 도장이 이미 내려간 뒤라 이름표 「홍귀달」과 알림 「관측이 하나 열렸다」만 보인다. 도장 문구는 e2e `tests/e2e/v5.spec.ts:802`이 검사). 눈이 열리면 눈 줄에 새 눈 + 알림 「관측이 하나 열렸다」(`p-34`). 고정 순간: 빈칸 「임금」이 호박 밑줄로 먹이 차오르고, 고정률 0 → 100% 숫자가 차오르며 머리에 「고정됨」(`p-25`→`p-26`). 복원 카드에서 일시 「세종 26년 2월 20일」, 내가 채운 칸만 밝게, 이웃 기록도 함께 돌아옴(`p-27`).

- **왜 강점인가**: 「만지는 맛」(규칙 10)이 핵심 동작마다 있다. 보상이 숫자(고정률)·물건(도장)·세계(복원 카드)로 세 겹이다.

### 증거 7 — 그날의 방: 정보 디자인
- **본 것**: 11:40 방 도면(`p-36-ep1-room-merge.png`) — 청록 가는 선, 고른 눈의 시야 부채꼴(옅은 채움), 사람은 성 한 글자 원(「이」「윤」), 겹친 사람 「×2」 두 겹 원, 모르는 사람 점선 「?」, 병풍·문 라벨. 모순 보기(`p-47`): 들림 반경 원, 자리 탭 → 「말한 자리」까지 선 + 「약 9칸」, 결론 낱말(또렷/흐림) 없음 — 플레이어가 기하를 보고 판단. 「들은 말 놓기」 칩 → 자리 탭 → 그 자리에 「?」가 생기며 바로 이어짐(`p-40`→`p-41`).

### 증거 8 — 접근성
- **대비**: 단말 글자 `hanji #e9dfc6` / 바탕 `ink0 #0b0a09` ≥14:1, 보조 ≥7:1(ART_DIRECTION_V5 §2). 한지 위 먹 `#3a342f` 10:1.
- **터치**: 감사 결과 버튼·칩·카드·막대 칸 모두 ≥44×44. 44 미만은 **문장 안 낱말 링크의 폭**(점선 풀이 낱말 30~34px 폭, 높이는 44~48로 덧칸 확보)뿐 — WCAG 2.5.8도 문장 속 인라인 대상은 예외로 둔다.
- **색만으로 뜻을 전하지 않음**: 모순 = ⚠ + 문구(`p-47`), 닫힌 눈 = 다른 모양(가로줄, `p-49`), 증인만 본 줄 = 점선 + 「실록이 적지 않은 일」.
- **한글 읽기 병기**: 한자는 늘 「언문(諺文)」 꼴(`p-07` 말풍선, `p-13` 카드 「최만리(崔萬理)」). 컷 속 한자 두루마리도 세부 탭으로 「부제학 최만리(副提學 崔萬理)」(`p-08-ep0-detail.png`). e2e는 화면마다 `bareHanja()`로 읽기 없는 한자를 0으로 검사(`tests/e2e/v5.spec.ts:27-30`).
- **시간 압박 없음**, 글자 크기 「크게」·움직임 줄이기·힌트 단계 설정(`p-06-settings.png`).

### 증거 10 — 코드로 정의된 아트, temp 관리
- **본 것**: v5 화면(`src/ui`, `src/shell`)은 옛 탑다운 스프라이트 레지스트리 `src/game/art`를 **한 번도 import하지 않는다**(grep 0건). 컷은 전부 `src/game/pov` 코드에서 구운 것, UI 아이콘·눈 4상태·문서 겉장(`p-62`)도 코드 픽셀.
- `SPRITE_META`의 `temp` 53건(`src/game/art/registry.ts:259-270` 등)은 은퇴한 v4 탑다운 자산이며 ART_DIRECTION_V5 §12가 「컷 렌더러에서 은퇴, 지우지 않음」으로 처리. 각 항목에 무엇을 고증해야 하는지(`needsReference`)까지 적혀 있다 — 규칙 7의 「임시는 temp로 표시」를 오히려 모범적으로 지킨 증거.

### 증거 11 — 테스트 커버리지
- e2e `tests/e2e/v5.spec.ts` 1,338줄 10개 테스트: 새 게임 Ep0→Ep1 실제 탭 완주(`:225`), 360×740 작은 탭 대상 44px(`:1078`), 조작 QA(`:1147`), 가로 회전(`:1252`), 데스크톱 프레임(`:1270`), 시트 끌어 내리기 진짜 터치(`:1288`), 저장 이어하기(`:1318`). 검사 항목 예: 아래 막대 높이 ≤56·칸 ≥44(`:132-147`), 배너 몸통이 탭을 통과(`:300-312`), 알림이 이름표를 덮지 않음(`:625-633`), 도면 표시 간격 ≥44(`:722-727`).
- 단위 테스트 539개 통과(컷 매니페스트·제스처·한자 읽기·용어·방 기하 포함).
- **왜 강점인가**: UI 품질을 「느낌」이 아니라 회귀 테스트로 지킨다. 출시 뒤 패치로 무너지지 않는다.

## 5. 결론 — 무죄 주장

출시 수준의 판단 기준은 「결함이 없는가」가 아니라 **「핵심 경험이 완성되었고 남은 결함이 싸게 고쳐지는가」**다.

- 핵심 경험: 새 게임에서 Ep1 예고까지 실제 터치로 끊김·오류 없이 완주. 보기(정수 배율 픽셀 컷) → 만지기(44px 탭, 밀기, 길게 누르기) → 판정(데이터, 공짜 실패) → 보상(도장·먹 번짐·복원 카드)이 모두 동작.
- 규칙 준수: 세로 전용(규칙 8), 한 초점·버튼 ≤3·팝업 0·5동사(규칙 9), 해 보며 배우기(규칙 10), 코드 아트·temp 표시(규칙 7), 한글 읽기(규칙 11) — 위 증거로 확인.
- 남은 결함은 아래 표가 전부이며 합계 반나절 이하.
